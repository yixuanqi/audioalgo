# 0032 混合任务区域边界

2026-10-23，P3-02。

PreparedPlan只读模型、目录和格式；沿用全局结构检查和单一输出选择闭包。离线能力是执行边界，NativePlan保持task_boundary_required。NativePlan元数据准入提取为共享函数，纯算法、发布C ABI v1不变。

原生连通分量不能直接当区域：A→B与A→Python→B会在合并A/B后形成区域环。采用确定性的边收缩，每次只合并native_region并核查商图DAG，最终按拓扑序输出任务及依赖。节点在计划中恰出现一次；边保存原始(node,port)及通道基址，参数含默认值为值拷贝。未知typed端口和离线变时序当前明确拒绝，不映射为PCM通道。

RunService的下一消费者负责拥有音频物化结果、执行真实JUCE区域和注册的离线工厂；虚拟源/收集端只属于投影，不写回项目。不按算法名称在通用执行器添加分支。整次运行代码冻结和最终发布仍单独验收。
