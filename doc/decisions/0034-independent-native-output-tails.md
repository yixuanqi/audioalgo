# 独立原生输出尾长（内部命名固定帧合同）

后续扩展：内部流式EOS与选短输出的有界排空已由[ADR0035](0035-per-port-stream-eos.md)实现并验收；下文流式前置拒绝保留本ADR初始范围，C ABI v1限制继续有效。

2026-10-23。已有节点级 `tail_frames` 不能表达同一处理器两个输出分别保留2/5帧尾部。以最大值裁剪每个输出会给短输出虚增有效样本。验收期望是1025帧输入分别产生1027/1030帧，数值由两个独立FIR公式给定，共享处理器每帧只执行一次。

在内部 `NodeExecutionCapabilities` 增加可选完整 `output_tail_frames` 映射。空映射保留已有节点级合同；非空映射必须恰好声明全部输出，节点级 `tail_frames` 必须等于其最大值，原有固定帧、已知延迟、有限补零预算均继续约束。此片仅支持命名固定块处理；流式EOS接口需要逐端口结束通知的后续实现，因此该组合在创建工厂前拒绝。发布C ABI v1不新增字段、不改变布局或独立消费者合同。

纯计划逐边读取源端口的累计尾长，输入结束帧和所选输出使用同一事实；节点的标量累计尾长保留所有输出最大值供适配器有界执行。JUCE命名适配器在各输出的明确结束帧后写零。一次原生区域统一补偿JUCE图延迟，物化时分别裁剪每个输出的尾长/有效区间，不通过静音推断结束。

跨任务输入长度或有效区间不同仍显式拒绝，不能隐式补齐后混音。没有逐端口声明的多输出尾部旧准入保留。此片不会使完整AR-15.e/AR-18.e或R5/R6自动通过。
