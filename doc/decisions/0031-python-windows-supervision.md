# 0031 — C++ 后台进程监督

2026-10-23。run_python_task 是同步后台 API，持有请求直到返回；不用于音频回调或GUI消息处理。

每项任务使用显式Python解释器、独立新工作目录、随机令牌和回环TCP。Windows进程以 suspended/no-window 创建，先加入具有 KILL_ON_JOB_CLOSE 的 Job Object 再运行，启动时限定继承句柄；stdout/stderr 各自线程排空，总量计数和最多64KiB保留尾部。协议与数据管道分离，控制长度上限1MiB。停止时关闭Job也回收主进程已退出后的剩余子进程。

取消从宿主稳定标志到达后发协作消息，2秒仍未终止则回收整个job；受控无响应/真实子进程测试在总5秒预算内结束。EOF、协议/身份错误、进程退出是明确失败，不因进程仍活着继续空转。启动stderr即使调用方不请求统计也进入诊断；异常/数值错误后可启动下一项任务。

C++写入planar float32 NPY及明确sidecar。返回时独立验证有界大小、dtype/shape、采样率、稳定通道ID、有效区间，并对同一份已读字节计算SHA和构造音频，避免前后读取不同文件版本。数据进入C++自有AudioBuffer后不再借用Python内存。

当前实现按任务启动进程，代码/环境在每项任务开始冻结；性能优化、共享运行服务目录与混合图尚未交付。C++ worker消费者和故障测试是后端证据，不等于真实GUI/CLI E2E-03、完整AR-18或最终打包通过。进程机制用于可回收生命周期，不宣称用户代码安全沙箱。
