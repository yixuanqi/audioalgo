# 逐端口流式EOS与所选短输出的有界排空

2026-10-23，接续ADR0034。内部固定帧流式节点的完整输出尾长映射将成为可准入合同；C ABI v1保持原边界。各输出分别获得逻辑结束帧、剩余有效前缀和一次EOS确认机会，不得用最长输出的结束帧替代短输出。零进展预算必须大于0，未知延迟/尾部、缺失补零预算或需要flush的算法继续拒绝。

先以真实图用例记录当前 `tail_ports_profile_unsupported` Red。独立期望是F480输入476帧时main/side尾长2/5，分别478/481帧；side跨越固定帧边界。F512输入508以及1025帧输入亦覆盖。选择main时仍须在有界范围内驱动side确认EOS，不能把main扩成side长度。

图的可发布raw长度仍为所选输出对齐长度加图延迟。实际处理终点取该长度与闭包内所有流式节点已声明的绝对输出终点的最大值。额外处理只用于有界EOS排空，不进入短输出WAV或有效区间；统计另记 `drain_padding_frames`。闭外节点仍不创建。未知能力不靠删除准入判断进入图。

元数据、适配器逐端口EOS、图驱动终点和raw截取属于同一行为的最小协调实现。原“流式+端口尾长一律拒绝”负例随此明确合同改成零进展预算拒绝，保留严格前置诊断；原AR-15.c无进展/早EOS/缺EOS/零分配/恢复断言继续回归。各父项、C ABI扩展和完整异步/借用组合仍单独判定。

失败定位补充：输入帧已消费、长输出未确认EOS而耗尽进展预算时，诊断除节点外还应携带实际阻塞输出端口（本用例side）。以现有空端口诊断为真实Red，再补通用未完成端口定位，不增加算法分支或修改预算。
