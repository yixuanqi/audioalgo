# 原生用户节点 ABI v1（P1）

2026-10-22。按交付约束 P1，新建独立安装组件 AudioAlgoNodeSDK，导出纯 C 函数表，不把现有 C++ NodeRegistry/虚接口作为 DLL ABI。

v1 沿用当前已验证的同速率/同通道 N 入 N 出全块 PCM 能力。manifest 与 DLL 内嵌描述双向核对，注册在 registry 副本上完成后一次提交，工厂与实例使用共享模块租约。实例先在 DLL 内销毁，再释放模块；GUI/CLI 通过同一 host assembly 发现，通用图/表单/调度器无算法分支。

生命周期、固定宽度/结构大小、长度、借用/释放方写在公开头文件。所有字段通过宿主 descriptor 共用规则校验；格式、ABI、缺 DLL/入口、重复插件ID、描述不匹配都有定位诊断。调用方不承诺恢复插件内访问冲突。Windows LoadLibraryEx 使用包目录和系统/用户声明路径解析依赖，不把进程当前目录插入查找链。

v1 无延迟尾部/EOS/部分消费协商；不为 P1 先建空 FIFO 协议。P2 按真实消费者扩展 SDK/后端，必要时通过新版本导出，v1 语义不变。更新仅关闭进程后重建插件、部署、重启，EXE hash 不变。UPN 精确映射与桌面/正式离线环境缺项另列，不能据自动化子集声称全部通过。
