# 0026 — 帧内逐端口消费与产出

2026-10-23。AR-15.c/GRAPH-07 的第一个可执行切片。

内部 C++ Node SDK 增加借用 streaming view 与调用方持有的逐端口 consumed/produced 计数。固定帧适配器保留每个端口尚未消费的数据及尚未填满的输出，每次只提供剩余区间。NeedMoreInput 不导致丢弃整帧，也不等于运行结束。所有端口累计达到 F 后才发布这一帧。

每次实际进展增加有界的整数累计；连续无进展次数达到描述预算（1～1024）即失败。超出输入区间/输出容量、未知状态均为结构化错误，定位 node/port，当前块清零，重新 prepare 可以恢复。正常路径的指针、view、计数与 FIFO 均在 prepare 分配。

真实 Speex 薄适配通过这个接口运行，原库 oracle 保持不变。测试另以两个输入分别消费17/23、两个输出分别产生11/19的节点覆盖不同速度、接线互换、输出选择、短尾和多种宿主块长。

这不是公开 DLL C ABI v1 的变更。已发布 ABI v1 继续整帧消费/产出；manifest 不能声明内部 streaming 能力。此切片只在已经缓冲的固定帧内推进；EOS、跨帧等待、有限尾部和完成协议尚未实现。AR-15.c 保留 remaining_contracts，不能据三个子集测试通过宣称整项通过。
