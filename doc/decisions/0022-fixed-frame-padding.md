# 固定帧 FIFO 的显式尾帧策略

2026-10-22，P2第一片。已出现真实 Red：480/512串联在host1、输入1帧被计划拒绝；固定节点prepare收到host1024而不是算法帧长。

新增 FixedFrameEndPolicy，默认 reject_partial，保持旧 AR-06.e 拒绝契约。算法明确声明 zero_pad 时，允许任意host分块，通过每端口固定容量FIFO只向算法交付完整F帧。缓冲本身引入 F-1 样本延迟，由通用 wrapper 报给 JUCE；区域末端只裁剪一次该延迟，输入耗尽后补零完成最后所需帧。保持输入样本数/原有效区间，补零不扩大有效区间。

此策略只解决全消费/全产出固定帧节点，不声称实现 NeedMoreInput、部分消费产出或算法自身尾音/未知延迟。默认拒绝的旧节点不改期望；后续Speex节点须基于真实算法契约显式选择策略。FIFO容量/峰值按每通道帧数可查，prepare分配，正常process不分配。
