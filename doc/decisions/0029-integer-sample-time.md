# 0029 — 整数样本时间映射

2026-10-23。纯 core 的 map_sample_frame/interval 和 SampleFrameClock 不依赖 JUCE/节点/项目。位置映射采用绝对位置向下取整；区间分别映射首尾，避免把每块持续时间单独舍入后相加。流式时钟携带有理数余数，零采样率和整数溢出失败，advance 失败时不改变状态。该接口映射时间，不对 PCM 重采样。

真实图按实际宿主块累计纳秒时钟，RunService 报告 raw/aligned duration 与 alignment offset 纳秒、舍入规则。已有样本计数、有效区间、文件 hash 和原始产物仍是音频对齐依据。FIR真实文件用例核对1477/487/990样本的纳秒字段。安装后的独立纯算法消费者执行十分钟48→16k映射，发布 core 库实际导出此实现。
