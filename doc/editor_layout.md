# 调整编辑区与查看打印

主窗口采用与编辑区一致的暗色标题栏。最小化、最大化、关闭与标题栏拖动继续由JUCE窗口管理。

节点库与画布之间、画布与Inspector之间，以及画布与底部波形/日志之间都有可拖动的分隔条。工作台的定义与源码、源码与检查日志之间也有分隔条。将鼠标移到短握柄附近，光标会变为调整大小；拖动改变面板大小，双击恢复该面板的默认大小。分隔条获得焦点后也可使用对应方向键调整。

面板有最小尺寸，避免把画布、源码或日志完全挤没。调整只影响本次界面布局，不修改工程、节点位置、计算revision、草稿正文或已检查版本；当前不跨应用重启保存这些面板尺寸。

Python的`process(inputs, params, state)`按音频块调用，在函数内每次`print()`就会产生一行。当前“检查/试跑”使用513帧输入、每块最多127帧，因此会调用5次（127×4＋5）；正式Run的次数由实际输入帧数及块长决定，与检查日志分开展示。少量可见行不代表完整输出，日志可滚动，也可拖大检查日志区或使用Copy logs。

如果只希望每次运行打印一次，可使用节点自己的`state`记录是否已打印；每次重新Run会按节点生命周期重新建立状态。不要为了减少打印次数改动音频分块或丢弃音频数据。

当前组件预览与自动化范围见`build/reports/loops/NI0015-resizable-workspace/`。组件渲染并非操作系统桌面截图，原生标题栏拖动/最大化、DPI及真实桌面验收仍待执行。更新后需要保存并退出旧窗口，再运行仓库的`build_and_run.cmd`启动最新构建；开发过程不会自动关闭或重启用户窗口。
